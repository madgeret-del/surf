📚 About Surf AI Agent

Surf is an open-source AI agent that converts natural language instructions into GUI actions (click, type, scroll, etc.). It works with any LLM provider via configurable base URL and API key.

🎯 Key Features:

  • Multi-provider support (OpenAI, Mistral, Anthropic, Groq, etc.)
  • Configurable base URL and API key
  • 9 GUI action types (click, scroll, type, press key, etc.)
  • Natural language to actions conversion
  • Lightweight and fast
  • Open source (MIT License)

Supported Actions:

  • click
  • double_click
  • scroll
  • type

 

  • press_key
  • move_mouse
  • wait
  • focus

Supported Providers:

  • OpenAI
  • Mistral
  • Anthropic
  • Groq

 

  • Ollama
  • Cohere
  • Any OpenAI-compatible
  • Custom APIs

⚠️ This is a Static Demo

This GitHub Pages version is static only. It simulates the Surf functionality in your browser. For full functionality with real API calls and GUI control:

  • Deploy the Docker version on RunPod/Railway/Replit
  • Use the Python library directly
  • Deploy to Hugging Face Spaces (with backend)
