# Surf AI Agent - Hugging Face Spaces

A static HTML demo of Surf AI Agent for deployment on Hugging Face Spaces (FREE tier).

## 🚀 Deploy to Hugging Face Spaces

### Step 1: Create a New Space
1. Go to [https://huggingface.co/spaces](https://huggingface.co/spaces)
2. Click **"Create new Space"**
3. Select **"Static"** (this is the FREE option)
4. Name your space (e.g., `surf-ai-agent`)

### Step 2: Upload Files
1. Upload the contents of this `huggingface/` folder:
   - `app.py`
   - `requirements.txt`
   - `static/index.html`

### Step 3: Configure Space
1. **Hardware:** CPU (default, free)
2. **Space type:** Static (free)
3. **Visibility:** Public or Private

### Step 4: Deploy!
- Click **"App"** tab
- Your space will deploy automatically
- Access at: `https://[your-username]-surf-ai-agent.hf.space`

## 💡 How It Works

This is a **static HTML demo** that:
- Runs entirely in your browser
- Simulates the Surf AI Agent functionality
- Generates GUI actions from natural language
- Stores configuration in browser localStorage
- **No backend required** (perfect for free static spaces)

### Features:
✅ Configure LLM provider (OpenAI, Mistral, Ollama, etc.)
✅ Enter natural language instructions
✅ See generated actions in real-time
✅ Save configuration to browser
✅ Beautiful dark theme UI

### Limitations (Static Version):
❌ No actual API calls (simulated only)
❌ No real GUI control (would need backend)
❌ Actions are generated by simple pattern matching

## 🔧 For Full Functionality

To get **real API calls and GUI control**, deploy the full version:

### Option 1: Docker Container (RunPod, etc.)
```bash
git clone https://github.com/madgeret-del/surf.git
cd surf
docker build -t surf .
docker run -p 8080:8080 -e SURF_API_KEY=your-key surf
```

### Option 2: Python Backend
```python
from surf import SurfAgent, SurfConfig

config = SurfConfig(
    base_url="https://api.openai.com/v1",
    api_key="your-api-key"
)

with SurfAgent(config) as agent:
    result = agent.run("Click at 100,200 and type Hello")
    print(result.actions_executed)
```

## 🎨 Customization

### Change Colors
Edit the Tailwind CSS classes in `static/index.html`:
- `bg-gray-800` - Background colors
- `text-cyan-400` - Accent colors
- `gradient-to-r from-cyan-500 to-emerald-500` - Button gradients

### Add More Providers
Edit the `<select>` dropdown in `static/index.html`:
```html
<option value="https://your-api.com/v1">Your Provider</option>
```

### Add More Actions
Edit the `parseInstruction()` function in `static/index.html` to add support for more action types.
