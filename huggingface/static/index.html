ℹ️ About Surf AI Agent

Surf is an AI agent that converts natural language instructions into GUI actions (click, type, scroll, etc.). It works with any LLM provider via configurable base URL and API key.

Note: This is a static demo running in your browser. The actual GUI actions are simulated. To connect to a real desktop environment like E2B, you would need to deploy the full Surf agent with a backend connection.

Supported Actions:

  • Click
  • Double-Click
  • Scroll
  • Type

 

  • Press Key
  • Move Mouse
  • Wait
  • Focus

Supported Providers:

  • OpenAI
  • Mistral
  • Anthropic
  • Ollama

 

  • Any OpenAI-compatible
  • Custom APIs
  • Local LLMs
